## 8 · THE STATION'S OWN CHANGES, made on this mission

Five real defects were found and fixed while making this brief possible — all in the station's own record, all
measured before and after:

1. **`src/scs.js` → `canonRaw` — THE SOUL HUNT HAD NEVER READ A FILE.** It returned `await r.text()` of the GitHub
   **contents API**, which answers with a JSON envelope whose `content` is the file base64-encoded. Every hunt read
   `{"name":"…","content":"<base64>"}` instead of the record; the card's promise *"the SOUL comes back VERBATIM"*
   returned **0 lines on every hunt ever run**. Proof, captured live before the fix: a hunt for `mailala` returned
   snippets reading `L2: "name": "MAILALA-HANDOFF.md",` and `soulCount 0`. Now decoded (base64 → UTF-8, with a raw
   media-type fallback for files the API hands back empty).
2. **`src/scs.js` → the SOUL's ORDER.** Soul lines were capped at 48 in *worker-completion order*, so on a hunt for
   Mailala+website an off-topic record took every slot and `CANON/MAILALA-PROMPT-REGISTER.md` — the register of the
   very prompts the sovereign ordered preserved — contributed **nothing**. Now ordered by the hunt's own doctrine:
   name-hit first (*"the term is in the path itself — the strongest signal there is"*), then term count, then
   SOUL-bearing path. **Verified after:** a hunt for `mailala website` leads with the register and returns all ten
   SOUL prompts verbatim.
3. **`src/scs.js` → the terms.** A command's own **destination** was being tokenised into the search
   (`https`, `org`, `cmd`, `perchance`), and `all`/`every`/`everything`/`everywhere`/`priority` matched half the
   canon. URLs are now removed whole, and those words are furniture, not terms.
4. **`src/scout.js` → `/PhoenixScout all …` PROBED NOTHING.** The whole argument was matched against sector ids as
   one string, so a word list naming no sector produced an **empty sweep — which renders as reconnaissance.**
   `all`/`every`/`everything` now mean the whole map, a named sector still narrows it, an unmatched list falls back
   to the whole map, and the report prints its **SCOPE**.
5. **`src/scs.js` → a dead term is now named.** Terms are ORed, so one good term hid a dead one. Measured: the
   sovereign spells it **"Mailhala"**, the canon writes **"Mailala"** — a hunt for his own spelling silently missed
   the register. The card now reports `NO RECORD HOLDS: mailhala`, with the rule attached: *not found by this
   sweep is never "does not exist"*.
