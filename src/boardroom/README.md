# The Boardroom — room law (src/boardroom/)

Seven seats, one question at a time, organic talk. The sovereign, Mr. Hobbs,
has the final word; the table advises; HQ orders.

## Files
- `seats/<id>.md` — each executive's LAW: mandate, lens, voice, red lines,
  standing orders (enforceable gates, briefed live), best practices, powers
  and limits, relations, threads. Curated; the room reads standing orders.
- `memory/<id>.md` — each executive's durable memory, chronological, latest
  at the bottom. The room reads the tail; fresh lines land here when the
  agent files them after wraps. The browser overlay (`seatmem`) carries the
  newest lines between filings.

## Room rules (provenance + hygiene)
- Everything read live, nothing guessed, nothing stamped that didn't run.
- Transcript is append-only. What is SENT to the model may be clipped
  (pasted walls ride along otherwise); the record itself is never rewritten.
- Never paste live secrets into the room — no tokens, no keys. Once bitten:
  a pasted GitHub token sealed itself into the archive and bled into the
  ledger before it was scrubbed. Say the word and a proper secrets shelf
  gets built instead.
- Unwrapped sittings are set aside (UNSEALED), never dropped — live table
  and orphan drafts alike.
