# Awesome Perchance [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of open-source projects built on or for [Perchance](https://perchance.org) — the
> declarative generator platform.

**Why this list exists.** Measured on **2026-09-24**: GitHub holds **271 repositories** that mention
Perchance, the highest-starred of them has **69 stars** (an unofficial Python image API), and there was
**no index of any kind** — a search for `awesome perchance` returned **zero** repositories. The market
had no front door. This is that door.

Star counts below were read from the GitHub API on **2026-09-24** and are stated as measured, not
as remembered. This list is a snapshot with a date on it, not a promise about today.

## The reference implementation

The first full application in the field — a platform-hosted generator is open source by nature, and
this one ships its whole tree (a command station with a self-editing engine, a mesh, a sync pipeline
and a register):

- **[PrAis Command Station](https://perchance.org/phoenix-rising-ai-solutions-agent99-mastermind)** —
  a self-editing Perchance command station: a declarative engine, an art-directed identity system, a
  connected-generator mesh, and `relay.js` — tree hashing, content-addressed idempotent delivery and
  post-hoc verification. Live demo, public source. *(This entry is the list's maintainer; disclosed as
  such.)*

*If you are building something in the same tier — an application rather than a wrapper — open a PR and
take the top slot next to it.*

## Contributing

Open a pull request adding one line to the right section:

```
- **[owner/repo](https://github.com/owner/repo)** — N★ — what it actually does.
```

**The entry bar** (this is what keeps the list worth linking to):

1. It must actually be about **Perchance** — the platform, its generators, its DSL, its API. Name
   collisions go in the section above, not in the sections below it.
2. It must **work**: a README, a runnable entry point, or a link to a generator that opens.
3. It must have **a sentence** explaining what it does. "Perchance stuff" is not a sentence.
4. It must not be **abandoned and broken**. Archived and working is fine — archived and 404 is not.
5. No affiliate links, no paid placement. The list is not for sale, which is exactly why it is worth
   something.
