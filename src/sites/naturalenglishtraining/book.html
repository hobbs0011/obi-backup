Why the form works offlinedesign note

A form that only works with a server up loses the enquiry the moment the wifi drops — which in a café in District 2 is most of the afternoon. So this form writes to your device first, verifies the write by reading it back, and only then offers to send it. The four lanes are listed honestly: DEVICE and HANDOFF always work; the API works the moment the coach deploys the endpoint; the STATION lane is available when the site is opened from the PrAiS command station.

If the API lane is BLOCKED, nothing is lost: your enquiry is in the outbox on this device and is re-sent automatically on your next visit once the endpoint answers. The outbox clears only after a real OK response for each record.
